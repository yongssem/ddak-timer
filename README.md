# 우리반 타이머

초등 교실 전자칠판용 풀스크린 타이머. 단일 HTML 파일로 동작합니다.

## 실행
`index.html`을 브라우저로 바로 열거나 간이 서버 실행:

```bash
python -m http.server 5173
```

## 단축키
- **Space** — 시작 / 일시정지
- **R** — 리셋
- **F** — 풀스크린 토글

## 프리셋
1분 · 3분 · 5분 · 10분 · 15분

## 종료 연출
알림음 "땡땡땡" 3회 + 화면 깜빡임 + 폭죽

## 배포
Vercel 정적 호스팅. 빌드 명령 없음. 루트에 `index.html` 포함.
